# RAOP
# FIRST OP Project

A lightweight, local sovereign environment built with Python that runs a background server seamlessly alongside a custom client interface.

###  Features
- **Custom Splash Screen:** Features a neat "OP" startup window while initializing.
- **Silent Background Execution:** The local server runs quietly without any command prompt interruptions.
- **Offline Ready:** Fully localized and works without an internet connection.

###  Installation & Usage
If you just want to try out the app without dealing with Python source code:
1. Go to the **Releases** section on the right side of this repository.
2. Download the latest `dist1.zip` package.
3. Extract it and run **`Running.exe`**.

Enjoy, and feel free to share your feedback!
